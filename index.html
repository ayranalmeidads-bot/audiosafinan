A criação, alteração de perfil e redefinição administrativa de senhas exigem uma Edge Function segura com Supabase Admin API. Não são executadas no navegador.

Gestão administrativa indisponível até a integração do endpoint seguro no servidor. A chave service_role nunca deve ser colocada neste HTML ou JavaScript.
